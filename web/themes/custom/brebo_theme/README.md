# BREBO Theme 5.1.0

Volledig vervangend Drupal 11-theme voor het BREBO-platform.

## Installatie
1. Maak een back-up van `themes/custom/brebo_theme`.
2. Verwijder de bestaande map volledig.
3. Plaats de map `brebo_theme` uit deze release terug op dezelfde locatie.
4. Leeg de Drupal-cache met `drush cr` of via Prestaties.
5. Vernieuw de browser met `Ctrl + F5`.

De bestaande paginabanner-module wordt niet vervangen. Deze release corrigeert de themevolgorde en de uitlijning eromheen.
