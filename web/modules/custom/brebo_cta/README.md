# BREBO CTA

Configureerbaar CTA-blok voor Drupal 11.

## Versie 1.1

- compactere en beter gebalanceerde compositie;
- tekstbreedte geoptimaliseerd voor leesbaarheid;
- grotere primaire knop;
- verfijnde hoveranimatie voor knop en pijl;
- verbeterde tablet- en mobiele weergave;
- ondersteuning voor `prefers-reduced-motion`.

## Installatie

Plaats de map in `modules/custom/brebo_cta` en voer uit:

```bash
drush en brebo_cta -y
drush cr
```

Bij een upgrade volstaat het om de bestaande modulemap te overschrijven en daarna `drush cr` uit te voeren.
