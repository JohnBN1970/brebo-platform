# BREBO Drie Pijlers 2.2

Definitieve Drupal 10.3/11-module voor de homepage: Inzicht, Regie en Realisatie.

## Aanpassingen

- Blauwe en paarse BREBO-kleuren
- Eyebrow: Onze aanpak
- Compactere tussenruimtes
- Grote procespijlen op desktop
- Neerwaartse procespijlen op mobiel
- Doorlopende blauw-paarse lijn
- CTA's: Ontdek Inzicht, Ontdek Regie en Ontdek Realisatie

## Installatie

1. Pak de ZIP uit.
2. Upload de map `brebo_pillars` naar `platform/modules/custom/`.
3. Overschrijf de bestaande modulebestanden.
4. Leeg de Drupal-cache.

De kaarten linken naar `/inzicht`, `/regie` en `/realisatie`.
