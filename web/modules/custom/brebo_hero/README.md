# BREBO Hero

Vaste homepagehero voor BREBO Platform 1.0.

## Installatie

1. Upload de map `brebo_hero` naar `platform/modules/custom/`.
2. Ga in Drupal naar **Uitbreiden**.
3. Schakel **BREBO Hero** in.
4. Ga naar **Structuur → Blokindeling**.
5. Plaats het blok **BREBO Hero** in de regio `hero`.
6. Stel bij zichtbaarheid **Pagina's** in op `<front>`.
7. Sla het blok op en leeg de caches.

## Inhoud aanpassen

De vaste inhoud staat in:

`templates/brebo-hero.html.twig`

De vormgeving staat in:

`css/brebo-hero.css`
