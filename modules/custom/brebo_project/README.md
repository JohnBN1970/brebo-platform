# BREBO Project

`brebo_project` beheert projectobjecten binnen het BREBO-platform.

## Verantwoordelijkheid

De module levert uitsluitend de domeinregels en Drupalconfiguratie voor een revisioneerbaar projectobject.

## Runtimegebruik

De module gebruikt `brebo_runtime` voor:

- stable-ID-generatie met prefix `PRJ`;
- lifecyclevalidatie;
- verplicht revisiebeleid;
- permissionvalidatie.

## Buiten scope

Deze module bevat in deze sprint geen planning, urenregistratie, financiën, facturatie, CRM, frontend, API- of MCP-functionaliteit.

`brebo_knowledge` en `brebo_reference` worden niet aangepast.
