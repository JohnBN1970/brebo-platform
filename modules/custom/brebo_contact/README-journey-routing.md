# Situation-driven journey routing

The second choice in the BREBO customer journey determines the most relevant information page shown in the contact intake.

The first route choice remains useful context, but it does not determine the return link.

- Situations that still require understanding, diagnosis, comparison or technical advice point to **Kennis & advies**.
- Situations about preparation, procurement, contract formation, supervision, quality control or handover point to **Bouwbegeleiding**.
- Situations where the visitor is ready for actual repair, replacement, improvement or renovation point to **Onderhoud & renovatie**.

This keeps the contact intake situational: two visitors can start from the same main route and receive a different relevant information link after choosing a different second block.
