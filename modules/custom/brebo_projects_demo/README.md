# BREBO Projecten Demo

Deze losse demomodule voegt drie voorbeeldprojecten toe aan een bestaande
installatie van **BREBO Projecten**.

## Installeren

1. Laat de bestaande module `brebo_projects` actief staan.
2. Plaats `brebo_projects_demo` in `platform/modules/custom/`.
3. Activeer **BREBO Projecten Demo** via **Uitbreiden**.
4. Leeg de Drupal-cache.
5. Controleer de projecten via **Inhoud**.

De demomodule maakt alleen inhoud aan. Zij installeert geen contenttype,
velden, Views of displays en veroorzaakt daarom geen conflict met bestaande
configuratie.

De drie projecten worden gepubliceerd, uitgelicht en gesorteerd als 1, 2 en 3.
Bij een herinstallatie worden projecten met dezelfde titel niet opnieuw
aangemaakt.
