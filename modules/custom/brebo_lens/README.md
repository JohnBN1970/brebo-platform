# BREBO Lens 3.0

Premium interactieve Drupal 11-module voor de BREBO Lens.

## Nieuw in 3.0

- Zes wisselende procesfoto's in de centrale lens.
- Vloeiende crossfade en subtiele zoom.
- De procesring draait 60 graden mee per fase.
- Actieve fase krijgt een rustige puls.
- De wazige achtergrond wisselt mee met de geselecteerde fase.
- Tekstpaneel animeert bij iedere stap.
- Ondersteuning voor toetsenbordnavigatie en reduced motion.

## Afbeeldingen vervangen

Vervang bestanden in `images/lens/` met behoud van de namen:

- `01-begrijpen.webp`
- `02-analyseren.webp`
- `03-adviseren.webp`
- `04-organiseren.webp`
- `05-realiseren.webp`
- `06-borgen.webp`

Gebruik bij voorkeur liggende WebP-afbeeldingen van minimaal 1200 × 800 px.

## Installatie / update

Plaats de map in `modules/custom/brebo_lens` en leeg daarna de Drupal-cache:

```bash
drush cr
```
