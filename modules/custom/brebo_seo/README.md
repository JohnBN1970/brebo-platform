# BREBO SEO

Technische SEO-basis voor de publieke website.

De module voegt toe:
- canonical URLs voor publieke pagina's;
- meta descriptions voor de belangrijkste landingsroutes;
- Organization structured data;
- een publieke XML sitemap op `/sitemap.xml`;
- filtering zodat ongepubliceerde nodes niet via aliassen in de sitemap terechtkomen.

De module herschrijft geen websitecontent en verandert de klantreis niet. De commerciële hoofdas blijft levering en plaatsing van kozijnen en glas.
