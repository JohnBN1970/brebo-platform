# Operations

Deze sectie bevat informatie voor het veilig draaien en beheren van het platform.

Hier horen deploymentrunbooks, omgevingsinformatie zonder secrets, back-up en herstel, monitoring, incidentafhandeling, onderhoud en operationele controles. Architectuurbesluiten over deployment blijven als ADR in `00-governance/` geregistreerd.

Bestaande bestanden in `docs/deployment/` blijven tijdens de migratie beschikbaar.
