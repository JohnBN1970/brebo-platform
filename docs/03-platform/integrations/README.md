# Integraties

Deze sectie bevat technische mappings en contracten voor externe systemen.

Per integratie worden minimaal het bronsysteem, gegevensrichting, eigenaarschap, authenticatiemodel, foutafhandeling, auditvereisten en operationele afhankelijkheden vastgelegd.

Bedrijfsregels blijven in `01-enterprise/` of `02-business/`; generieke API-contracten blijven in `03-platform/api/`.
