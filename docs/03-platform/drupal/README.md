# Drupal-platformimplementatie

Deze map bevat de Drupal-specifieke implementatie van het BREBO-platform.

## Onderverdeling

- `architecture/`: Drupal-componenten, modulegrenzen en technische samenhang;
- `entity-mappings/`: mapping van canonieke informatieobjecten naar Drupal-entiteiten en velden;
- modulegebonden technische documentatie blijft bij voorkeur bij de betreffende custom module wanneer zij alleen die module betreft.

Drupal-documentatie mag niet zelfstandig canonieke bedrijfsconcepten herdefiniëren. Zij verwijst daarvoor naar `docs/01-enterprise/`.
