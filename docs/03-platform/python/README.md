# Python-services

Deze sectie bevat architectuur en implementatiemappings voor zelfstandige Python-services binnen het BREBO Platform.

Hier horen servicegrenzen, componentverantwoordelijkheden, runtimecontracten, queues, workers en service-specifieke afhankelijkheden. Gedeelde API-contracten blijven in `03-platform/api/`; techniekonafhankelijke bedrijfsconcepten blijven in `01-enterprise/`.

De aanwezigheid van deze map is geen toestemming om een service te bouwen: uitvoering vereist een goedgekeurde taak, architectuur en beveiligingskader.
