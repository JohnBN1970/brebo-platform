# Technische beveiligingsarchitectuur

Deze sectie bevat technische beveiligingsgrenzen voor platformcomponenten.

Hier horen identity- en accessmodellen, trust boundaries, secretsbeheer, tokenbeleid, auditlogging, dreigingsmodellen en technische beveiligingscontroles.

Formele risicoacceptaties en bindende beveiligingsbesluiten blijven in `00-governance/`. Operationele beveiligingsrunbooks horen in `06-operations/`.
