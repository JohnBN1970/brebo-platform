# API-contracten

Deze sectie bevat versieerbare API-contracten tussen BREBO-componenten en externe afnemers.

Hier horen endpoints, schemas, foutmodellen, versiebeleid, authenticatievereisten en compatibiliteitsafspraken. Implementatiecode blijft bij de betreffende service of applicatie.

Een API-document beschrijft het contract en mag niet afhankelijk zijn van niet-vastgelegde interne Drupal- of Python-details.
