# Platform

Deze sectie vertaalt het BREBO-model naar technische componenten.

## Hoofdonderdelen

- `drupal/` voor CMS, redactie, presentatie en Drupal-implementatiemappings;
- `python/` voor toekomstige zelfstandige services en automatisering;
- `api/` voor versieerbare contracten;
- `integrations/` voor externe systemen;
- `security/` voor technische beveiligingsarchitectuur.

Drupal blijft een belangrijke applicatie binnen het platform, maar is niet de enige mogelijke technische implementatielaag.
