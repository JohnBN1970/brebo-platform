# Besluiten

Deze map bevat formele, geregistreerde BREBO-besluiten en het centrale besluitenregister.

## Regels

- ieder besluit heeft één uniek besluitnummer;
- de actuele status staat in het centrale register;
- besluiten verwijzen naar relevante RFC's, ADR's, taken en validaties;
- inhoudelijke wijziging van een vastgesteld besluit gebeurt via een nieuw besluit of een expliciete vervanging;
- concepten en losse notities horen niet in deze map.

Bestaande besluiten worden pas hierheen verplaatst nadat het centrale besluitenregister is gereconcilieerd.
