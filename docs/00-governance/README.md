# Governance

Deze sectie bevat normatieve besturing van het BREBO Platform.

## Hier horen

- formele besluiten en besluitenregisters;
- Architecture Decision Records;
- Requests for Comments;
- architectuurprincipes;
- roadmap- en vrijgavebesluiten;
- document- en wijzigingsgovernance.

## Hier horen niet

- technische implementatiehandleidingen;
- operationele processen;
- module- of API-documentatie zonder bestuurlijk besluitkarakter.

Bestaande `docs/adr/`, `docs/rfc/` en `docs/decisions/` blijven tijdens de migratie actief en worden niet stilzwijgend vervangen.
