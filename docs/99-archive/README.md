# Archief

Deze sectie bevat uitsluitend documentatie die aantoonbaar is vervangen, ingetrokken of uitgefaseerd.

## Toelatingsregel

Een document wordt pas hier geplaatst wanneer:

1. de opvolger expliciet is aangewezen;
2. de status van het oude document op `vervangen` of `gearchiveerd` staat;
3. interne verwijzingen zijn bijgewerkt;
4. de reden en migratiedatum in het migratieregister zijn vastgelegd.

## Niet toegestaan

- actieve besluiten, ADR's of RFC's;
- actuele handleidingen of runbooks;
- documenten waarvan de status onzeker is;
- tijdelijke opslag voor nog te classificeren bestanden.

Archiveren is geen verwijdering: historie en herleidbaarheid blijven behouden.
