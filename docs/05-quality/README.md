# Quality

Deze sectie bevat aantoonbare kwaliteitsborging voor modellen, documentatie en software.

Hier horen acceptatiecriteria, validatierapporten, traceerbaarheid, conformiteitstoetsen, audits, kwaliteitsmetingen en testbewijs. Normatieve architectuurbesluiten blijven in `00-governance/`; uitvoerbare tests blijven bij de betreffende code of in `04-development/`.
