# Domeinmodel

Deze map bevat het techniekonafhankelijke BREBO-domeinmodel.

Het domeinmodel beschrijft bedrijfsconcepten, verantwoordelijkheden, relaties en grenzen zonder deze gelijk te stellen aan Drupal-entiteiten, databasevelden, API-resources of programmeerklassen.

Technische implementatiemappings verwijzen vanuit `docs/03-platform/` naar de canonieke definities in deze map.
