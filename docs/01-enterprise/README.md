# Enterprise

Deze sectie beschrijft BREBO onafhankelijk van een specifieke technische implementatie.

## Hier horen

- domeinmodel;
- Canonical Information Model;
- object- en waardenregisters;
- canonieke begrippen en definities;
- eigenaarschap en bron-van-waarheidregels;
- techniekonafhankelijke bedrijfsregels en relaties.

## Plaatsingsregel

Drupal-entiteiten, Python-klassen, databasevelden en API-paden zijn hier alleen toegestaan als verwijzing naar een afzonderlijke implementatiemapping. Zij definiëren het bedrijfsconcept niet.

Bestaande documenten in `docs/architecture/` worden pas na inhoudelijke classificatie naar deze sectie of `03-platform/` verplaatst.
