# Canonical Information Model

Deze map bevat het canonieke informatiemodel van BREBO.

Hier worden betekenis, identiteit, kernattributen en relaties van informatieobjecten technologie-onafhankelijk vastgelegd. Implementaties in Drupal, Python, API's en externe integraties mogen hiervan afwijken in vorm, maar niet stilzwijgend in betekenis.

Afwijkingen vereisen een expliciete mapping en, wanneer de canonieke betekenis verandert, een formeel architectuur- of besluittraject.
