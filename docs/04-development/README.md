# Development

Deze sectie bevat uitvoerbare afspraken voor ontwikkeling.

Hier horen branch- en commitregels, coding standards, teststrategie, CI, releaseproces, contributing-richtlijnen en lokale ontwikkelinstructies. Operationele deployments en productiebeheer horen in `06-operations/`.

## Normatieve ontwikkelstukken

- [`software-architecture-guide.md`](software-architecture-guide.md) — modulegrenzen, lagen, dependency injection, Drupal-conventies, teststrategie en Definition of Done;
- [`workflow.md`](workflow.md) — ontwikkelworkflow;
- [`git-scope.md`](git-scope.md) — Git-scope en repositoryafspraken.

Bestaande bestanden in oude ontwikkelpaden blijven alleen leidend zolang zij nog niet gecontroleerd zijn geclassificeerd en verplaatst. Het [`../migration-register.md`](../migration-register.md) registreert die overgang.
