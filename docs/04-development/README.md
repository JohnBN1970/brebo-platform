# Development

Deze sectie bevat uitvoerbare afspraken voor ontwikkeling.

Hier horen branch- en commitregels, coding standards, teststrategie, CI, releaseproces, contributing-richtlijnen en lokale ontwikkelinstructies. Operationele deployments en productiebeheer horen in `06-operations/`.

Bestaande bestanden in `docs/development/` blijven tijdens de migratie leidend totdat zij gecontroleerd zijn verplaatst.
